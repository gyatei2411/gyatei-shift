スタッフ名マスタ

スタッフの追加・削除と、各スタッフができるポジション（K / R2 / R2d / R1 / W / T）の設定を行えます。
ここで設定したポジションは、シフト表の「⚡自動割り当て」で使われます。
名前の横の ★優先 / 主婦 / 学生 で区分を選べます（もう一度押すと無印）。
シフトに入れる優先順位は ★優先 ＞ 主婦 ＞ 無印 ＞ 学生 です。
週□〜□回：〇をつけても全部は入らない人の希望回数。右側（上限）を超えては割り当てません。空欄なら制限なし。
人数を削るときは、希望回数に対する充足度が高い人から削ります（1人を3日削るのではなく、3人を1日ずつ）。

1部（9:00〜16:00）と 2部（16:00〜L）は別々に設定します。
2部のポジションは W と T の2つだけです。両方に入る人はシフト表に「R2→W」のように出ます（同じなら「W」のまま）。
K（調理場）は1部・2部を通してK。時間は 9-L になります（TやWには回りません）。
1部がWの人は2部もWのままです（Tには行きません）。
2部Tは必ず1日3名まで。
必ずT：1部がW以外の日は必ず2部Tにつける人（西川さん）。シフトに表記され、3名の1人として数えます。
応援T：2部Tへヘルプに行く人（青木さん）。シフトにTは表記せず、終業だけLまでになります（例：K 9-L）。3名には数えません。
応援Tの人が出勤する日は、3名のうち1人が16:30上がり（表記「R2→（T」）になります。
